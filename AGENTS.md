# Shaker end table project instructions

This repository is an illustrated class reference for Christopher Schwarz's "Simple Shaker End Table."

## Read first

Before planning, estimating, or changing project material, read:

1. `PROJECT_BASE.md`
2. `LUMBER_AND_WOODWORKING_TERMINOLOGY.md` for lumber, measurement, part, and joinery terminology
3. The original source linked from `PROJECT_BASE.md`
4. Any newer class notes or decisions recorded in the project base

## Source-of-truth order

1. Current class instructor directions and shop rules
2. Decisions explicitly recorded in `PROJECT_BASE.md`
3. The source article and its dimensioned drawing
4. Agent recommendations or assumptions

Never silently change a dimension, joint, material, or finish. Record the proposed change, its reason, and the connected parts it affects.

## Working rules

- Keep measurements in inches and write fractions as `1 1/8`, `3/8`, and so on.
- State dimension order in every cut list. The source uses thickness x width x length.
- Keep purchase sizes, rough-milling sizes, and finished dimensions separate.
- Check dependent dimensions before suggesting a cut. Drawer dimensions depend on the assembled opening; tenons depend on the actual mortises.
- Prefer test pieces for machine setups and finish schedules.
- Require a complete dry fit before glue-up. Check square, twist, reveals, and drawer clearance.
- Preserve attribution and the original source URL with derivative notes and images.
- Update the `PROJECT_BASE.md` decision table when a choice is settled.
- Keep `index.md` and the links in `_config.yml` current when adding or renaming a public reference page.

## Shop safety

Class shop rules and the instructor's direction control every machine operation. Do not recommend removing guards or using unsupported freehand cuts. For small or narrow parts, describe the required workholding, push blocks, sled, sacrificial fence, or alternate hand-tool method. Flag operations that require instructor demonstration or approval.

## Public-source boundary

The public repository intentionally omits the downloaded source PDF and complete article-page renders. Link to the publisher's original PDF instead. Selected illustrations are included for educational reference with attribution in `ATTRIBUTION.md`.
